# YouTube Clone (MERN)

## Features
- User Authentication (Login/Register)
- Upload Videos
- Play YouTube & MP4 videos
- Like / Dislike system
- Comment system (Add, Edit, Delete)
- Channel creation
- Edit & Delete videos

## Tech Stack
- React (Vite)
- Node.js + Express
- MongoDB Atlas
- JWT Authentication

## Run Project

### Backend
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev
